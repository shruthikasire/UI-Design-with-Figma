# UI-Design-with-Figma

** Project Overview**

The Study Plans project is designed to make students' learning more organized and productive. It provides a simple platform where students can plan their daily studies, access learning materials, and get assistance from an AI study chatbot.

**Main Modules**

1. Welcome Page: Introduces users to the platform.
2. Login and Sign-up: Allows students to access their accounts.
3. AI Study Chatbot: Provides study-related assistance.
4. Study Planner: Helps students organize their study schedules.
5. Study Plan Management: Helps students manage and update their plans.
6. Learning Resources: Provides access to useful study materials.


**Target Users**

- School students
- College students
- Learners preparing for exams

**Benefits**

- Better time management
- Organized study schedules
- Easy access to learning resources
- Support for independent learning
- Improved study habits

**Project Status**

UI/UX design project – created using Figma.

**Future Scope**

The project can be developed into a fully functional website with user accounts, saved study plans, reminders, progress tracking, and AI-powered study support.
